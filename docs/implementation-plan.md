# 实施与验收计划

本计划承接已批准的设计。没有可用的 writing-plans 技能，使用此文件记录等价的实施步骤；不增加设计确认轮次。

1. 创建纯 Java 工作负载、运行器、有界直方图及 CSV 指标输出。
2. 创建显式选择 JDK 的编译、运行、结果对比脚本。
3. 编写中文上手指南、完整调优教程及实验记录模板。
4. 编译为 Java 21 字节码，检验结果等价、容量约束、输入和八个实验组合。
5. 实际验证 JFR 记录、GC 日志及对比脚本。保存本机兼容性实测记录，注明 JDK 版本与限制。

完成标准：读者按 README 能运行第一组实验，找到源码中的问题，采集证据并对比优化前后；无需 Maven、服务或外部压测工具。
