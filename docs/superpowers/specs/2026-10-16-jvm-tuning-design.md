# JVM 调优学习实验设计

用户已于 2026-10-16 同意四个实验和中文教程，并授权按该方案实施。

## 目标与边界

面向 JDK 21 HotSpot，以纯 Java、无外部依赖的程序练习基线、采样、诊断、改动、复测。Windows PowerShell 是主要入口；也提供直接 java/javac 命令。不是生产压测器或严谨微基准框架。

## 三种路线与选择

选择纯 Java 实验：依赖少、问题直接、便于阅读。Spring Boot 更接近 Web 服务，但引入框架和 HTTP 干扰；JMH 更适合微基准，但不覆盖完整运维排障。因此后两者留给后续学习。

## 组件

- 命令行入口：解析实验、模式、并发、预热、时长、缓存上限、输出路径。
- 四种工作负载：allocation、leak、cpu、lock，各有 bad/fixed 两种模式。
- 运行器：固定数量平台线程，先预热再测量，按时间自动退出。
- 指标：吞吐、近似任务耗时 P95/P99、堆、GC 次数/累计时间、工作线程分配字节、进程 CPU 时间。
- PowerShell 脚本：JDK 识别、编译、运行、结果比较、自检。
- 中文教程：从第一条运行命令到 GC、JFR、线程栈和堆分析。

数据流：参数 → 工作负载 → 固定并发运行 → 指标/GC 日志/JFR → 汇总 CSV → 单因素对比。

## 实验行为

allocation 通过逃逸到字段的临时缓冲区保证分配可观测，fixed 复用每线程缓冲区；CPU 实验以有限键空间缓存相同计算的结果；锁实验将模拟慢操作移出共享锁；leak 实验用可达缓存保留对象，fixed 对缓存设定容量。

leak 默认最多保留 64 MiB 到达上限后停止增长并继续运行，不以 OOM 为默认教学条件；bounded cache 默认 8 MiB。默认堆为 128 MiB、四线程、5 秒预热和 30 秒测量，leak 默认不预热。

## 指标约束

固定并发闭环负载。耗时从任务调用到完成，包括锁等待，不包括外部排队或网络。分位数是有界内存直方图估算值。预热不纳入吞吐和耗时；预热对缓存/堆的影响保留。GC 指标来自 MXBean 差值，不当作精确 STW 时间。进程 CPU 包含运行期间的 GC/JIT，分配速率仅统计工作线程。

## 错误与验证

无效参数快速失败，工作线程异常传播到主线程。使用输出目录隔离每次实验。JDK 版本不为 21 时默认拒绝，允许用户显式启用兼容性模式。检查任务结果等价、缓存容量、分位数、输入校验，以及八种组合能限时退出并生成可解析结果。验证 GC 日志和 JFR 文件。

## 当前环境

可用 JDK 为 J:\JDK\jdk23；默认 JAVA_HOME 指向此处。未在已检查目录找到 JDK 21。使用 javac --release 21 校验语言/API 兼容性，在 JDK 23 上执行烟雾测试时明确注明不是 JDK 21 实测。
